# Moving Video Cinema

A standalone HTML5/CSS/JS web cinema player featuring:
- **Playback Controls**: Play/pause, seek timeline, loop toggle, playback speed (0.5x–2.0x), mute/unmute, and volume slider.
- **Visual & Theater Modes**: Custom ambient theater lighting glow with color picker, video color filters (Cinema Warm, B&W Noir, Vivid HDR, Vintage Film), Picture-in-Picture, and Fullscreen.
- **Subtitles**: Load local `.vtt` or `.srt` subtitle files directly in the browser with a CC toggle.
- **Interactive Playlist**: Pre-loaded sample videos, custom URL addition, reordering, removal, and auto-advance toggle.
- **Keyboard Shortcuts**: Full shortcut support with an interactive legend (`?`).

## Usage
Open `index.html` in any modern web browser.
